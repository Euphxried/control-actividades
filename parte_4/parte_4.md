1. Explica la diferencia entre Git y GitHub.

R= git es una función local sobre control de versiones de proyectos y programas y github es la plataforma en la nube
   donde se almacenan estos mismos facilitando el trabajo en equipo

-------------------------------------------------------------------------------------------------------------------------

2. Explica para qué sirve .gitignore.

R= Para que git no suba los nombres de los archivos que están dentro del .gitignore

-------------------------------------------------------------------------------------------------------------------------

3. Explica por qué .venv no debe almacenarse normalmente en GitHub.

R= Porque contiene información sobre drivers y especificaciones técnicas del equipo donde fue creado el proyecto

-------------------------------------------------------------------------------------------------------------------------

4. Explica para qué sirve requirements.txt.

R= Para dar a conocer que librerías o extensiones se necesitan para trabajar comodamente con el proyecto de forma local

-------------------------------------------------------------------------------------------------------------------------

5. Explica la diferencia entre Stage, Commit y Push.

R= Stage es donde se preparan o guardan los cambios de forma local, Commit es hacer un registro del cambio y Push es
   subir el cambio a la nube

-------------------------------------------------------------------------------------------------------------------------

6. Explica por qué un repositorio puede tener varios commits antes de realizar un push.

R= Porque se pueden hacer varios cambios ya sea en la rama maestra o en algunas otras
